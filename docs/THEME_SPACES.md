# 空间式主题

诗之境、秘法藏书院、金灯书房、苔庭晨雾和极夜星图的主页使用独立空间布局，不复用仪表盘 hero 和课程网格。棱镜实验舱保持已验收的研究仪表盘；课程、笔记、账号和偏好数据不迁移。

## 主页的不同空间

- 金灯书房：胡桃木墙面、夜窗与黄铜台灯，左侧留有书签的阅读纸页，右侧带金属夹的课程簿。课程是连续目录，不是与魔法主题相同的藏书架。
- 苔庭晨雾：树冠、远山、透叶光线与缓慢流动的薄雾；课程作为叶形路标沿小径错落排布，继续阅读是上次驻足的位置。
- 极夜星图：全景夜空与黄铜观测仪，课程以不同的原创星座点线图分布在圆形坐标网中，悬停点亮坐标。SECTOR 为课程目录编号，不冒充真实天文坐标。
- 三者的最近笔记、加星索引、搜索匹配、继续阅读和学期选择均保留；显示真实笔记量与阅读记录，不把翻阅记录当作掌握程度。长课程名完整换行，课程入口顺序不变。

## 课程章节页

六个主题的章节入口使用 `CourseSpace.tsx`，不仅替换横幅，而且改变目录结构：

| 主题 | 章节入口 | 整理台 |
| --- | --- | --- |
| 金灯书房 | 布面装订册、连续目录与黄铜页签 | 案头手记 |
| 苔庭晨雾 | 带路径节点的错落章节列表 | 林间札记 |
| 极夜星图 | 连线星图、错落坐标节点 | 观测手记 |
| 棱镜实验舱 | 网格研究索引、紧凑编号行 | 研究工作台 |
| 诗之境 | 卷轴、竖排诗境、连续卷目 | 案边整理 |
| 秘法藏书院 | 左侧扉页、右侧章节目录的打开古籍 | 誊写书桌 |

章节标题、原编号、顺序、英文副标题、课程切换和整理功能均保留；不改写资料，不自动调用 AI。目录显示真实笔记数量与“有阅读记录”，不将阅读记录冒充完成度。目录页的整理台可收起，两个空间主题延续主页的紧凑导航栏。

`course-spaces.css` 的外框和整理台规则仅作用于 `data-course-space=true`。打开章节后卸载目录空间，退出到课程时恢复；正文、课件图和专注模式不采用装饰性目录排版。

阅读区的 Markdown 标题使用稳定组件与上下文传递星标状态，避免进度或主题更新导致页标题重新挂载、清空未保存的备注。备注视觉样式不变。

## 体验约定

- 点击任一主题卡片后立即关闭选择面板、退出文档并进入对应主页顶部，包括点击当前已选主题；不等待偏好保存请求完成。清除旧搜索与待跳页目标，但不改笔记或阅读记录。仅调节氛围强度不离开当前页面、不关闭面板。保存失败回滚偏好，并重新打开面板显示重试提示。
- 诗之境：整屏原创山水，竖排诗句，纸笺课程入口；展开纸笺后进入课程。30 组公版古典诗文按阅读时间缓慢流转；六种情景母题保留为界面基调，具体画面逐首配置，不再仅由母题决定。景物、天空和诗句同步过渡，支持“留住此境”。不按日期固定诗句，不推断用户情绪。
- `lib/poetic-scenery.ts` 以稳定诗歌 ID 完整配置 30 首的光线、地形和意象：海月对应开阔海面与月影，长风破浪对应云帆，烟雨对应细雨与竹杖行人，小荷对应池水、新荷和蜻蜓，松泉对应松枝与石上清流，东篱对应菊花与篱笆，登高对应楼阁或高峰，元夕对应花灯与星光。不是给同一张山水图单纯换色，也不把无关红豆、船只添加给同母题的所有诗。
- 点击诗句本身切换到下一首；无前后切换箭头、无按钮白底或边框，键盘 Tab / Enter / Space 也可使用。手动切换用短过渡，重置 96 秒流转计时；自动切换保持缓慢淡入淡出。停留时仍可点击换诗，且保持停留状态。主页和课程页共用当前诗境，刷新保留。扩容保留原六首的索引兼容旧状态。
- 秘法藏书院：整屏拱窗、纵深书架、星仪、浮烛；课程以不同装帧的实体藏书置于书架，悬停抬起，点击展开后进入课程。全部为原创矢量场景，无外部图片依赖，不使用影视 IP。
- 全局搜索保留原有内容结果及跳页；主页对应书/纸笺同时突出显示，不匹配课程变淡但仍可访问。搜索跨学期时仍由结果列表进入目标笔记。
- 最近笔记和加星索引默认收起，由案头按钮打开抽屉。最近笔记显示最新 12 篇，加星索引显示全部收藏；支持关闭按钮、点击遮罩及 Escape，关闭后焦点返回原入口。
- 继续阅读仍使用已有页码记录；进入正文后不加载整屏场景，原课件、加星、备注、搜索与专注阅读保持原样。
- 减少动态效果偏好下不播放入场动画或场景循环动画；首次开启诗境默认停留。最低氛围强度也暂停循环运动。

## 实现边界与验收

`ImmersiveHome.tsx` 管理诗境和魔法的课程入口、阅读索引和打开过渡；`AtmosphericHome.tsx` 管理书房、森林与星空主页。`WorldScenery.tsx` / `HomeScenery.tsx` 只提供不可交互、对辅助技术隐藏的原创矢量背景。诗境的 `PoeticScenery.tsx` 同时用于整屏主页、课程横幅和主题预览，避免语境与配景脱节；几何坐标保留两位小数以保证服务端和浏览器渲染一致。`worlds.css` / `home-spaces.css` 的紧凑导航规则仅应用于 `data-world-home=true`，不改变文档页布局。

验收：1920×1080、1440×900 下课程可见且无横向溢出；长课程名不被装帧截断；所有空间主题均能打开课程、搜索跳页、继续阅读、使用索引；从文档选择六种主题均直接进入主页，氛围强度调整不触发导航，保存失败可重试，刷新保留偏好；诗境暂停/恢复、30 首完整循环、点击切换与重新计时正常，每首光线、地形与意象符合配置且主页/课程页一致，浏览器无 hydration 警告。诗句按钮透明且没有前后箭头，正文浅色/深色专注阅读正常。已有响应式规则保留。

运行文件数据库的 UI 回归时建议使用 `--workers=1`，避免多个测试进程同时改写同一份测试 JSON 数据。测试数据与用户的 `data/app-db.json` 隔离。
