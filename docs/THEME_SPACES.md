# 空间式主题

诗之境与秘法藏书院的主页使用独立空间布局，不复用仪表盘 hero 和课程网格。其他四个主题保持原有布局；课程、笔记、账号和偏好数据不迁移。

## 体验约定

- 诗之境：整屏原创山水，竖排诗句，纸笺课程入口；展开纸笺后进入课程。六组诗意继续按阅读时间缓慢流转，景物、天空和诗句同步过渡，支持“留住此境”。不按日期固定诗句，不推断用户情绪。
- 秘法藏书院：整屏拱窗、纵深书架、星仪、浮烛；课程以不同装帧的实体藏书置于书架，悬停抬起，点击展开后进入课程。全部为原创矢量场景，无外部图片依赖，不使用影视 IP。
- 全局搜索保留原有内容结果及跳页；主页对应书/纸笺同时突出显示，不匹配课程变淡但仍可访问。搜索跨学期时仍由结果列表进入目标笔记。
- 最近笔记和加星索引默认收起，由案头按钮打开抽屉。最近笔记显示最新 12 篇，加星索引显示全部收藏；支持关闭按钮、点击遮罩及 Escape，关闭后焦点返回原入口。
- 继续阅读仍使用已有页码记录；进入正文后不加载整屏场景，原课件、加星、备注、搜索与专注阅读保持原样。
- 减少动态效果偏好下不播放入场动画或场景循环动画；首次开启诗境默认停留。最低氛围强度也暂停循环运动。

## 实现边界与验收

`ImmersiveHome.tsx` 管理课程入口、阅读索引和打开过渡；`WorldScenery.tsx` 只提供不可交互、对辅助技术隐藏的背景。`worlds.css` 的紧凑导航规则仅应用于 `data-world-home=true`，不改变文档页布局。

验收：1920×1080、1440×900 下课程可见且无横向溢出；长课程名不被装帧截断；两种主题均能展开课程、搜索跳页、继续阅读、使用索引；切换主题和刷新保留偏好；诗境暂停/恢复正常，正文浅色/深色专注阅读正常。已有响应式规则保留。

运行文件数据库的 UI 回归时建议使用 `--workers=1`，避免多个测试进程同时改写同一份测试 JSON 数据。测试数据与用户的 `data/app-db.json` 隔离。
