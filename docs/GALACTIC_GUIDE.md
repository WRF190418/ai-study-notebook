# 银河系搭车客指南主题

这是一个随身携带、仍在修订的电子指南，不是星空主题的换色。原创舷窗与远行星提供空间尺度；略旧的设备边框、双页索引、编者附注与一杯茶，提供人的尺度。文案用平静的观察制造反差，不解释人生哲学，也不评价用户的效率、成绩或学习状态。

## 入口与真实功能

- 在侧栏「空间主题」选择「银河系搭车客指南」，立即进入对应主页；偏好通过原有队列保存，失败沿用原有提示与回滚。
- 「已知领域」是当前学期的真实课程索引，显示章节、笔记数量；条目进入课程分册，章节顺序不变。
- 「旅途尚未结束」使用真实阅读位置；无页码时显示最近笔记，无笔记时明确提示。最近笔记与加星索引可打开、跳转、用 Esc 关闭并返回原按钮。
- 「不大可能按钮」仅轮换正常航行、鲸与盆栽的原创场景及短讯。不写偏好、不改笔记、不请求 AI 或其他外部服务。没有随机错误、假警报、抖动或强制弹窗。
- 课程目录采用指南分册；正文保持清晰的暖色纸面，星标、原图、OCR、搜索与 AI 整理使用既有组件。专注阅读仍保留自己的浅色/深色设置。

## 视觉与交互边界

蓝灰深空、灰绿设备、旧纸色内页与简洁排版形成对比。只有行星和茶汽缓慢变化，不在正文叠加装饰。氛围设为「极简」或系统设置减少动画时关闭持续运动。窄屏沿用原有兼容性，搜索与欢迎区不叠压。

`GalacticScenery.tsx` 是原创 SVG，无外部图片依赖。`GalacticHome.tsx` 承接真实工作区及教程的内存工作区，保留既有自动带看选择器。`galactic-guide.css` 的主题规则不影响其他主题；正文内容、公式与页码不会因主题改变。

## 验证

隔离测试账号使用六门课程验证主页、场景轮换无写请求、笔记/加星索引、搜索、正文公式、专注深浅模式、课程分册、保存后重载与数据保持不变。还需运行跨主题入口/目录回归，以及新主题下完整自动教程；测试不读取或修改个人笔记。

```text
npx playwright test tests/theme-entry.spec.ts tests/course-spaces.spec.ts tests/reading-focus.spec.ts --project=desktop --workers=1
npx playwright test tests/tutorial.spec.ts --project=desktop --workers=1 --grep "safely in galactic-guide"

```
