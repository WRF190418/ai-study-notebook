# 银河系搭车客指南主题

这是一本随身携带、仍在修订的指南。原创舷窗与巨大的行星提供空间尺度；有厚度与书脊的旧式随身本、索引、贴入的书签夹页与一杯茶提供人的尺度。文案用平静的观察制造反差，不解释人生哲学，也不评价用户的效率、成绩或学习状态。

## 入口与真实功能

- 在侧栏主动选择本主题，进入主页并打开独立的实体封面。点击封面约 0.68 秒展开进入索引；可以直接跳过或用 Esc 关闭。减少动画时立即进入。默认聚焦封面，原生 modal 隔离背景交互，打开后聚焦索引标题。
- 封面请求只存在于当前 UI 状态，不写本地存储。刷新、返回主页、课程导航、调节氛围以及教程内的主题操作不触发封面；保存失败会撤去封面、恢复偏好并显示失败提示，即使此前已是本主题也不会遮挡错误。
- 「已知领域」是当前学期的真实课程索引，显示章节、笔记数量；条目进入课程分册，章节顺序不变。
- 「上次读到这里」的夹页使用真实阅读位置；无页码时显示最近笔记，无笔记时明确提示。书页顶部的最近笔记与加星索引可打开、跳转、用 Esc 关闭并返回原按钮。
- 编者边注可点击翻阅八条原创短文；夹页中「宇宙，以及其他」展开明确标注的虚构条目，通过交叉参阅循环阅读宇宙、其他和茶。它们不进入真实课程、搜索结果或笔记正文。
- 机身下沿的实体按键带按下反馈，按顺序轮换六则主题虚构短讯。鲸与盆栽会出现在窗外；「没有发生任何事」与纸条事件保留上一个窗外场景，确实不会改变画面。不写偏好、不改笔记、不请求 AI 或其他外部服务，没有随机错误、假警报、抖动或自动弹窗。
- 课程目录采用指南分册；正文保持清晰的暖色纸面，星标、原图、OCR、搜索与 AI 整理使用既有组件。专注阅读仍保留自己的浅色/深色设置。

## 视觉与交互边界

深空、灰金色大行星、灰绿机身与旧纸色内页形成对比。主页减少巨幅标题，物件本身是主体。书脊、纸页厚度、标签页、纸胶带、局部细纹与压下的按键建立触感，不在正文铺纹理。只有行星和茶汽缓慢变化；「极简」或减少动画时关闭持续运动。窄屏保留兼容性，搜索与欢迎区不叠压。

`GalacticScenery.tsx` 为原创 SVG，`GalacticCover.tsx` 为原生 dialog 与 CSS 物件，无新增外部依赖。`GalacticHome.tsx` 承接真实工作区与教程内存工作区，保留自动带看选择器。主题规则不影响其他主题；正文内容、公式与页码不会因主题改变。`lib/galactic-guide.ts` 单独保存主题虚构文案和场景映射。
