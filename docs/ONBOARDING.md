# 交互式新手教程

## 使用流程

首次登录显示全窗口沉浸介绍：AI 整理 → 理解与原页对照 → 自己留下重点 → 续读与专注。使用当前主题的本地矢量场景，无声音、不强制浏览器全屏。约每 4.7 秒切换一幕，最后一幕由用户点击开始。可暂停、逐幕点选、跳过介绍或退出教程；系统开启减少动画时不自动播放，后台标签页暂停计时。

侧栏「新手指导」随时打开目录。主线顺序：

1. 课程、章节、笔记。
2. 概念框架、逐页讲解、对应原课件、插图放大、完整附录。
3. 加星、自动备注弹窗、保存与重新编辑。
4. 当前笔记星标列表折叠、跳页、悬浮返回、取消星标、主页全局索引。
5. 正文搜索、课程筛选、结果路径与页码、定位、返回结果、清除。
6. 返回章节、快速上滚返回的规则、自动记录位置、主页续读、最近笔记。
7. 侧栏专注、顶部靠近展开、深浅模式、退出与 Esc。
8. 图片英文、数字和标点选择复制，关闭选字，插图与课件图片库。
9. 闪卡与思维导图。
10. Codex 默认整理方式；可选内置 AI 的目标要求、文字/大纲/图片/课件、上传、输出风格、整理、命令、附图、费用及修改风险、整理台收展。
11. 学期课程切换、主题、氛围强度、诗境切换/暂停/恢复、退出账号、重开教程、临时网址使用条件。

每一步只有一个操作目标，真实点击、输入、选择、成功复制或关闭操作后推进；只在阅读说明、风险提示时出现确认按钮。不会把找不到控件当成成功，也不会使用自动点击来模拟用户已掌握。目标暂不可见时提示「重来本节」。可收起气泡，退出按钮仍留在顶部。

## 临时练习资料与安全边界

- 复用真实主页、课程、阅读、星标、搜索、图片和整理台，不为教程另画一套假界面。
- 所有课程/章节/笔记 ID 使用 `tutorial-` 前缀，只在组件内存存在；练习标题、顶部状态和整理台均明确标记。退出或完成时恢复进入前的个人工作区、页面、阅读区域、深浅模式和布局；不清空个人笔记。
- 星标、备注、阅读位置和主题练习只更新内存。示例原页是 `public/tutorial/learning-map.svg`，不是教师课件或 AI 的实时生成结果。正式原页映射仍要求真实账号的 `/api/media/<assetId>`，没有放宽原有规则。
- 教学图使用明确标示的预置选字层，保证无材料的新用户也可练习英文、数字和标点的选择复制；真实图片仍按需调用本地英文 OCR 接口。教程不能宣称进行了真实 OCR 或提供翻译。
- 教学区所有文件上传、插图提交、内置 AI 整理/命令、退出账号均禁用；提交函数也有独立防护，不依赖按钮 disabled。不会调用付费 AI，不上传用户文件，不重写或删除资料。
- 默认推荐把文件交给 Codex，说明课程、学期和范围。内置 AI 仅为主动选择的替代入口，并强调费用、结果核验与命令影响范围。

## 进度

本浏览器按用户存储 `study-note-tutorial:v3:<userId>`，只含版本、步骤 ID、介绍状态、已完成小节 ID 和 paused/completed；不存账号、课件或正文。每个步骤更新一次。退出为暂停；只有全部小节均完成且最后手动确认时，才标记整个教程完成。单独学习最后一节会回到目录，提示剩余未完成小节，不虚报完成。目录为完成的小节显示勾选。续学从上次所在小节起点开始，并明确说明，不声称恢复失效的弹窗和选字状态。

`/api/onboarding` 的旧字段仅表示已关闭首次提示，避免每次登录强弹；不再作为学完的证明。清浏览器数据、换设备或本地存储受限可能无法恢复进度；存储失败显示提示，仍可使用教程。

## 实现与验证

- `lib/tutorial.ts`：小节、逐步文案、目标选择器、动作类型、进度校验和完成事件。
- `lib/tutorial-demo.ts`：内存工作区、原创教学正文和示例文字坐标。
- `components/InteractiveTutorial.tsx`：开场、目录、气泡定位、步骤推进、恢复和退出。
- `components/NotebookApp.tsx`：工作区隔离/恢复、操作防护和现有界面的目标标记。
- `app/tutorial.css`：主题继承、克制的金色目标边框、小气泡、无全屏遮罩的练习阶段、减少动画。

气泡监听实际界面状态，目标只在进入步骤时滚动一次，不会持续把读者拉回目标。每 180ms 更新可见目标矩形与位置，裁切滚动区域；原图预览使用原生 dialog 顶层时，将指引一同放入该 dialog，保证教程不会被模态遮住。

验证命令（隔离数据目录由 Playwright 配置指定，不使用真实资料）：

```text
npm run typecheck
npx playwright test tests/tutorial.spec.ts --project=desktop --workers=1
npx playwright test tests/tutorial-safety.spec.ts --project=desktop --workers=1
npx playwright test tests/tutorial.spec.ts --project=mobile --workers=1 --grep "exit, restart"
npm run build
```

完整流程测试逐一覆盖六种主题，包含真实拖动选字和复制，断言课程、笔记、星标、阅读位置、偏好及诗境本地偏好不变，并监测没有 AI/OCR/正式写入请求。另有真实个人笔记恢复、原生弹窗中退出、存储被拒绝、直接提交表单被拦截、目标缺失恢复、未学完不得虚报完成的检查。小屏幕只检查教程入口/退出/续学兼容，不替代桌面完整交互验收。其他现有功能测试应通过「退出教程」关闭首次提示，不能用「跳过介绍」代替退出。
