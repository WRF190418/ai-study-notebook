# 自动带看新手教程

## 从独立世界开始

首次进入或从侧栏打开「新手指导」，立即呈现独立的全窗口开场，不先显示主页目录。不强制浏览器全屏，无声音、无外部视频：使用本地 CSS 光晕、轨道、书页与知识连线，保证文字对比和清晰度。

开场三幕依次讲「AI 将材料连成知识」「逐页理解与原页核对」「续读、专注与个人空间」。标题和说明逐字浮出，每幕约 5.6 秒，约 17 秒后自动进入带看。可以暂停、选幕、跳过介绍或随时退出；已暂停的历史教程可选「接着上次看」。减少动画设置会关闭漂移、位移与逐字动画，但不取消自动推进。切换到后台暂停计时。

## 连续演示，由浅入深

没有需要逐章点击的课程目录。小气泡先解释，再由动画光标移动、点击、输入或拖选，最后留出观察时间，自动衔接下一步及下一段。默认每步约 6–10 秒，依文案长度调整；可选 0.75×、1×、1.5×、2×。

1. 课程 → 章节 → 笔记，先建立基本导航。
2. 概念框架 → 逐页讲解 → 原课件按钮 → 插图放大 → 完整附录。
3. 加星 → 自动备注弹窗 → 保存与重编辑。
4. 笔记顶部星标列表 → 折叠展开 → 跳页 → 悬浮返回 → 取消星标 → 主页全局索引。
5. 搜索正文 → 课程筛选 → 结果路径与页码 → 定位 → 返回结果 → 清除。
6. 返回章节与快速上滚规则 → 自动记住位置 → 主页续读与最近笔记。
7. 侧栏专注 → 鼠标靠近才展开的顶部工具 → 深浅模式 → 退出与 Esc。
8. 图片英文、数字、标点的选择复制 → 插图与课件图片库。
9. 闪卡与思维导图。
10. 重点讲 AI：优先把材料交给 Codex；再介绍可选内置 AI 的整理要求、四种输入、上传、输出风格、整理与命令、费用和修改风险、整理台收展。
11. 学期与课程切换 → 主题 → 氛围强度 → 诗句切换与暂停 → 账号退出及临时网址条件。装饰性功能放在主干之后。

每一段开始有承接说明。自动推进表示「已带看」，不宣称用户已操作或掌握。暂停、速度与退出保持可见；每段还可重播或跳过。用户手动滚动会暂停，暂停后自行点击界面则会在继续时重播本段，避免自动演示重复开关。找不到目标超过 10 秒会暂停并提示重播或跳过，不虚报成功。

## 教学资料与安全边界

- 使用真实组件和导航，不另画假功能界面；课程、章节、笔记采用内存中的 tutorial- ID。
- 所有星标、备注、阅读位置、主题练习仅在内存更新。退出或完成时恢复进入前的个人工作区、页面、布局、深浅模式和阅读区域。诗境偏好也不写入个人本地状态。
- 示例原图为 public/tutorial/learning-map.svg，明确标示教学示例，不是教师课件。正式原图映射规则不变。
- 教学图片使用预置文字坐标，展示英文、数字和标点拖选，不冒充实时 OCR。演示只指向复制入口，**不会自动覆盖用户剪贴板**。正式图片的识别和复制流程不变，也未新增翻译功能。
- 真实上传、图片插入提交、AI 整理和命令、账号退出均禁用，且提交函数独立防护。不发起付费 AI、不上传材料、不修改正式笔记。
- 指引置于播放遮罩之上，避免演示时误点正式界面；暂停后允许查看。原生图片 dialog 打开时，指引移入该 dialog，保证退出按钮始终可用。

## 本地进度

按用户保存在 study-note-tutorial:v4:<userId>，只含版本、步骤、介绍状态、已看段落与 paused/completed，不含课件或正文。

每段完整播完才记作已看；跳过不算完成。只有所有段落均看完，才标记教程 completed。缺段时结束页如实提示未完整看完，续看从第一个未看段落的起点恢复；中途退出从所在段落起点恢复，不尝试恢复过期的选字和弹窗。开场退出不会覆盖已有续看位置。

/api/onboarding 只表示已关闭首次提示，不代表学完。存储被拒绝会提示，教程仍可播放；换浏览器、设备或清理本地数据后可能失去进度。

## 实现与验证

- lib/tutorial.ts：顺序、承接、文案、目标与进度校验。
- lib/tutorial-playback.ts：受控演示动作、逐字输入、选字，不触碰真实上传或提交。
- components/InteractiveTutorial.tsx：独立开场、可暂停时钟、动画光标、气泡定位、完整与部分结束状态。
- components/NotebookApp.tsx：内存工作区及恢复、功能防护。
- app/tutorial.css：开场场景、气泡、动画光标、弱遮罩及减少动画适配。

目标进入步骤时滚动一次；每 140ms 更新目标边界，兼容内容滚动区域及顶层图片 dialog。自动计时使用可暂停的动画帧时钟，后台不推进。

验证（隔离测试数据，不使用真实笔记；数据库恢复测试串行运行，避免跨进程并发写测试库）：

~~~text
npm run typecheck
npx playwright test tests/tutorial.spec.ts --project=desktop --workers=1
npx playwright test tests/tutorial-safety.spec.ts --project=desktop --workers=1
npx playwright test tests/tutorial.spec.ts --project=mobile --workers=1 --grep "pause, speed"
npm run build
~~~

完整带看逐一覆盖各主题的每一步，检查原生弹窗、选字结果、所有正式课程/笔记/星标/阅读位置/偏好不变，且无 AI、OCR 或正式写请求。另检验个人笔记恢复、弹窗中退出、进度存储受限、表单防护与暂停/重播/退出/续看。桌面为主要验收环境，小屏保留兼容性。
