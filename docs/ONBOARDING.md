# 手把手新手指导

入口：首次进入账号自动打开；以后点击左侧「新手指导」可随时重开。

指导分为十个可直接选择的步骤：主页续读、空间主题、课程章节、逐页阅读与原课件、星标备注、正文搜索、专注深色、图片选字复制、资料整理、闪卡与导图复习。

每步包含入口位置、按顺序的操作、预期结果、注意事项和实际跳转目的地。点击「带我……」后，关闭说明窗口，进入真实页面；悬浮提示保留步骤并框出操作目标。支持收起、展开、重新定位、返回完整指引、继续下一步或退出，不要求按顺序浏览，也不把浏览过指引当成已经学会。

桌面端提示会避开当前定位的操作目标；主题选择时默认收起以免遮住卡片。搜索结果不会因为收起提示而被关闭。完整指引支持 Tab 焦点循环和 Esc 关闭；在专注阅读中关闭指引不会同时退出专注。

## 真实数据与安全边界

- 跳转只使用当前账号课程、章节和笔记；必要时切换到目标笔记所属学期。
- 逐页阅读优先定位已有原课件按钮；星标练习需要真实页码；选字练习需要已保存图片。原图附录中的图片可自动展开以显示入口。
- 缺少前置资料时明确说明，不生成示例笔记、假星标或虚构复习资料。
- 指导不会自动加星、填备注、启动 OCR、上传文件、提交 AI 命令或调用付费 AI。
- 整理资料优先指引用户把课件发送给 Codex；内置整理台另行说明真实调用与修改资料的风险。
- 关闭或跳过只记录账号的首次指导已关闭状态，不修改课程、笔记或星标。
